# 🛒 E-Commerce Sales Analysis

> **Data Analyst Project – 2 | E-Commerce Sales Analysis**

An end-to-end **E-Commerce Sales Analysis** project focused on transforming raw sales data into meaningful business insights using **Excel, SQL, and Power BI**.

The project analyzes **15,000 sales records** to understand sales performance, profitability, customer purchasing behavior, product performance, payment preferences, and monthly sales trends.

---

## 📌 Project Overview

E-commerce businesses generate large amounts of transactional data every day. This project demonstrates how a data analyst can take raw sales data, clean and transform it, perform exploratory analysis, identify business trends, and present the findings through an interactive dashboard.

### 🎯 Objective

* Clean and prepare raw e-commerce sales data
* Analyze sales and profitability
* Identify top-performing products and categories
* Compare sales performance across states
* Analyze payment method preferences
* Understand monthly sales trends
* Build an interactive business dashboard
* Generate actionable business insights

---

## 📂 Dataset

The dataset contains **15,000 e-commerce sales records** with the following fields:

| Column             | Description                      |
| ------------------ | -------------------------------- |
| `Order_ID`         | Unique order identifier          |
| `Order_Date`       | Date of the order                |
| `Customer_ID`      | Unique customer identifier       |
| `Product_Category` | Category of the product          |
| `Product_Name`     | Name of the product              |
| `State`            | Customer's state                 |
| `City`             | Customer's city                  |
| `Payment_Mode`     | Payment method used              |
| `Quantity`         | Number of units purchased        |
| `Sales_Amount`     | Revenue generated from the order |
| `Discount`         | Discount applied                 |
| `Profit`           | Profit generated from the order  |
